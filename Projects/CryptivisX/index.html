CryptivisXOffline secure file encryption for Windows

CryptivisX is an offline Windows encryption tool that protects images, videos using one-time keys. Files are encrypted locally with a proprietary format and are designed to be decrypted only by CryptivisX. No cloud services. No tracking. Full local control.

Features

  • File encryption and decryption
  • Secure one time key system
  • Proprietary encryption format
  • Files encrypted by CryptivisX can only be decrypted by CryptivisX
  • Designed to be decrypted only by CryptivisX (currently no other software could decrypt that is encrypted by us)
  • Image and video support
  • QR code key export
  • Modern desktop UI
  • Runs fully offline
  • Windows native app
