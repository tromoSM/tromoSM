Easypycode documentation

Module functions

SetEazyTitle(x)

Sets the global title used for all Windows message boxes title created by this module.

you must set the title by SetEazyTitle() before using other functions.

Must not equal to "" or some function will fail.

pythonez.SetEazyTitle("Easypycode")

ReopenAsAdmin()

reopen the main window as admin.

pythonez.ReopenAsAdmin()

output:

Error(x)

Displays a Windows error message box with a red error icon.

pythonez.Error("Error : 500 internal server error")

output:

Info(x)

Displays an information message box with an info icon.

pythonez.Info("This is an info alert")

output:

Warning(x)

Displays an Warning message box with an warning icon.

pythonez.Warning("This is an warning alert")

output:

Ask(x,y,**z)

Ask a question and run functions depending on the answer

x is the question, y is whether the yes/no(True) buttons or ok(False) button is present and you can use z to run different function when clicked different buttons like this,

pythonez.Ask("Is grass green vro?",True,yes=function1,no=function2)

function1() will run if the yes is pressed and function2() will run if no is pressed.

output:

Colored(Color, Text)

Prints colored text to the console.

pythonez.Colored(ez.lightred,"colored text")

output:

Beep(Frequency, duration)

Produces a sound in a specific frequency(x) for a specific period of time(y).

Frequency(Hz/int), duration(s/int)

pythonez.Beep(500,5)

Countdown(timeleft)

Prints a live MM:SS countdown timer in the console.

timeleft(s/int)

pythonez.Countdown(5)

BeepCountdown(timeleft)

Prints a live MM:SS countdown timer that beeps during the last 3 seconds and double-beeps at the end.

timeleft(s/int)

pythonez.BeepCountdown(5)

Copy(text)

Copies the text to the clipboard

text(text/string)

pythonez.Copy("copy this to the clipboard")

Paste(text)

Returns text currently stored in the system clipboard.

text(text/string)

pythonprint(ez.Paste())

OpenInDefaultApp(path)

Opens a file or folder using the system’s default application.

path(abspath/string)

pythonez.OpenInDefaultApp("file.png")

Busy(action)

Shows or stops a console spinner (running in a different thread).

"RUN" → start spinner

"RESET" → stop spinner

pythonez.Busy("RUN")

ErrorText(text)

Prints a formatted red error message directly to the console.

pythonez.ErrorText("System failure :51")

output:

Alert(text,icon)

Generic Windows message box where you manually choose the icon

icon option - CautionIcon,InfoIcon,ErrorIcon,QuestionIcon

text(text/string), icon(icon/var)

pythonez.Alert("System failure :51",ez.ErrorIcon)

output:

FlashWindow(duration)

Flashes the console window in the taskbar for the given duration.

duration(s/int)

pythonez.FlashWindow(5)

output:

SendNotification(title,description)

Sends a notification with the title and the description (native windows)

title(title/string),description(description/string)

More info: Will raise "[WinError -2147024809] applicationId" if SetEazyTitle() is empty("")

pythonez.SendNotification("EazyPyCode documentation","EazyPyCode notification example.")

output:

CheckNetwork()

Returns True if the device is connected to the internet. False if the device isnt connected to the internet.

pythonif(ez.CheckNetwork()):
print("This device is connected to the internet")
else:
print("This device is not connected to the internet")

output:

CreateQR(content,FilePathWithName)

Creates a QR code and saves it to the path given.

Do not include the file extension(.png/.jpg) in the FilePathWithName

Output directory must exist when running.

pythonez.CreateQR("Example text","assets/images/qrcode")

output:

image will be saved "./assets/images/qrcode.png"

CreateBarcode(number,FilePathWithName)

Creates a Barcode and saves it to the path given.

Do not include the file extension(.png/.jpg) in the FilePathWithName

Output directory must exist when running.

The barcode number must include 12 digits

pythonez.CreateBarcode(241851545431,"assets/images/barcode")

output:

image will be saved "./assets/images/barcode.png"

GetDateAndTime(x)

Returns the currect time or date depending on the variable you choose from below,

  • ez.day
  • ez.month
  • ez.hour
  • ez.milisecond
  • ez.weekday
  • ez.second
  • ez.timeWithMicrosecond
  • ez.timestamp
pythonez.GetDateAndTime(ez.date)

output :

  • ez.day -> 16
  • ez.month -> 12
  • ez.hour -> 14
  • ez.milisecond -> 15416
  • ez.weekday -> tuesday
  • ez.second -> 45
  • ez.timeWithMicrosecond 14:37:45.15416
  • ez.timestamp -> 1765892265.15416

ConvertToMB(data,current)

Returns the given size as MB using Binary(1024).

You must choose one as the current data type to continue,

  • ez.Gigabytes
  • ez.Bytes
  • ez.Kilobytes
  • ez.Bits
  • ez.Terabytes
pythonez.ConvertToMB(1,ez.Gigabytes)

ReadFileAsText(path)

Returns the given file's content(data) as text

Returns the given file's content(data) as Bytes(Binary)

WriteFileAsText(path,data)

Writes the given file content(data) as text

pythonez.WriteFileAsText("./temp.py","yo")

WriteFileAsBinary(path,data)

Writes the given file content(data) as Bytes(Binary)

pythonez.WriteFileAsBinary("./temp.png",b"\x89PNG\r\n\x1a\n")
