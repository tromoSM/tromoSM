Installation


Download installer from Downloads and install.

Open terminal in your mac and run these,

brew tap tromosm/fluxlan brew install fluxlan

Download MacOS package from Downloads

And Open terminal in the folder containing the downloaded file and run,

chmod +x FluxLAN-macOS{-} ./FluxLAN-macOS{-}

Download Ubuntu package from Downloads

Open a terminal in the folder containing the downloaded file and run,

sudo apt install ./FluxLAN{-}-Ubuntu.deb

Make sure you have Python and Git installed.

Open the terminal in the folder you wish to install FluxLAN (make sure there's no files inside this folder) and Run these commands in your terminal

git clone https://github.com/tromoSM/FluxLAN.git .

After that,

pip install -r requirements.txt

Now run the app using,

python main.py
